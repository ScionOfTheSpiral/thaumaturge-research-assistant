# Thaumaturge Research Assistant

## Purpose
Threw together a quick research assistant for the Thaumaturge port version 1.0.2. Some of the aspects have changed inherently and some with how they are combined between Thaumcraft version 4, 5, and 6. The goal of this app is to find a valid path between 2 core aspects that the user chooses. The space between these 2 core aspects can be adjusted to fit the size of the research notes that are trying to be completed. I do recommend at least getting through some of the research notes first to get the full experience as it's quite a fun puzzle solver. After about 25 of them, it can get old.
